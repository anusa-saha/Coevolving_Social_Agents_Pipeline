# DAT (Dialogue Action Tokens) on CSA.
#
#   pip install -r requirements.txt
#   python -c "import nltk; nltk.download('punkt'); nltk.download('punkt_tab')"
#   python selftest.py
#
# Scenarios download from anusasaha/Coevolving_Social_Agents into data/raw/ on first use.
# Override with CSA_HF_REPO or CSA_RAW_DIR.
#
# NOTE what is NOT here: peft. DAT trains no adapter and touches no LM parameter -- the
# only trainable objects in the arm are a two-layer MLP and one matrix, both plain
# torch.nn. That is the method's central claim, and the dependency list is the cheapest
# place to see it is true.

# 4.37 is a HARD floor: Qwen2 architecture support landed there. Everything above it is
# absorbed by csa_core/compat.py. One further thing this arm needs specifically:
# generate(inputs_embeds=...) for a decoder-only model, which has worked since 4.27 and
# returns ONLY the new tokens from 4.30 or so. steering.py handles both behaviours.
transformers>=4.37
torch>=2.1

# Recommended: without it device_map is unavailable, so the model loads on CPU then moves.
accelerate

# Sentence trimming when a model starts speaking for someone else. Without it trimming is
# skipped, which changes transcripts relative to the other baselines.
nltk

# The replay buffer is npz; the TD3+BC sampler indexes numpy arrays.
numpy

# Fetches the scenario JSON. Already a transitive dep of transformers; named because
# paths.download_raw() imports it directly.
huggingface_hub
